# Automatic materials for every generated Grade 2 question

Isolated branch: preview/mission-all-questions-20260925. Base: ea53f57413aae62da0e15b68aaa264c770b71318, the other window's saved Make ten work, preserving Count on 9a458d2 and the user-confirmed fullscreen-exit f1a3e1c. The original branches and production main are not updated. Scope is all ten generated questions in the existing addition-within-20 pilot, not a complete Grade 2 curriculum.

Existing JOIN, Count on and Make ten controllers remain intact. The new complementary controller covers complete-ten, together, pair, story, practice, swap and check. Each current question has one observation picture and one automatically displayed solution, with a short fact and matching English/French teacher narration. No additional media buttons, downloaded video, paid speech provider or AI request is added. Story marks represent the exact objects described by the current story; practice and pair questions select an appropriate joining, counting-on or making-ten method from their numbers. Swap shows the same groups exchanging places. Missing-addend diagrams introduce exactly the required new counters only after responding; the expected answer is the missing addend, not ten.

All graphics, final positions, equations, captions and additional-question context derive from the existing generated numbers. Observations keep the answer hidden. The normal submission path reveals the exact solution and retains the existing incorrect-answer review gate. The new module never generates lessons, grades answers, advances a problem, changes dialogue rules, controls the microphone or changes fullscreen behavior. Pause, question input, dialogue, hidden documents, draft typing and dialogs suspend its movement. Saved frames are keyed by session ID, question role and numbers; language change and reload do not create another session. Only the existing New lesson action generates a new set. Same-origin/browser storage limits remain.

build-all-questions.mjs imports the entire existing build-make-ten.mjs chain before applying checked final-output anchors. Every existing material controller is synchronized before the selected-material return, preventing a prior problem's image from remaining on the next problem. All previous checks stay enabled; a new read-only CI job uses its own concurrency group, so it cannot cancel another window's checks.

New validation: 609 supported role/number combinations, 12,789 animation samples, object identities/positions, bilingual equations and non-mutating data; final built-material coverage over 120 generated sessions / 1,200 questions; and end-to-end traversal of all ten questions using the existing Next button. Each question receives text corrections and final recognized voice answers in English and French (40 submissions total). Final tests include session continuity, a problem-five reload, unique visible material, automatic solution movement, new-session reset, mobile layouts and fullscreen exit. The real VRM is loaded in CI; speech and recognition are simulated. Hardware microphone accuracy, every possible AI answer and a real 40-minute classroom run are not certified by these tests.

Local standalone visual fixture checks of the new complementary module were run without a network dependency. No asset list from the student's reference document is silently imported or treated as an automatic reuse license.
