# PC-first common programme, five teaching languages — first implementation

User direction: do not spend the initial phase matching every country's public curriculum. Build GEM common mathematics, science and English for learning levels 1–12; world history only for levels 7–12. Local society/history/language, art/music are optional modules supplied when needed. No advanced track. English/French/Nepali/Urdu/Swahili are teaching-language choices, not national-curriculum choices. Urdu and Swahili are stated defaults for the user's country-language shorthand, not claims of exclusive national languages. English remains the target language of the English subject even when explanations are localized.

Preserve the user-confirmed English/French Grade 2 sample and all old mobile functionality. This addition is a separate pc.html entry; it does not patch the original app, materials, input, dialogue, fullscreen controller or service worker. Build hashes check that original output is not touched by the PC step. New browser storage is isolated and switching language never regenerates a session. Existing deployed sample and main remain unchanged. No original Drive files or reference assets are modified.

Implemented in this phase: 5 language choices, shared catalogue (4 subjects and 12 learning levels, world-history floor 7), and a PC Grade 2 addition-within-20 language pilot across the same generated 10-question set. Reuses original makeSession, verified material geometry (JOIN, Count on, Make ten and all remaining roles), original VRM bundle and the fixed fullscreen exit controller. Two automatic material states per problem. Numbers, session, answer visibility and animation progress are preserved on language switch; new lesson is explicit. Urdu prose is right-to-left while mathematics stays left-to-right. Direct number answers accept ASCII, Devanagari and Arabic/Persian digits and common number words in all five languages. Draft translations in Nepali, Urdu and Swahili require a fluent classroom teacher's review.

Not complete: full Grade 1–12 subject curricula, Grade 2 science/English, world-history lessons, local options, professional translation certification, hardware TTS/ASR for every PC. Only Grade 2 addition is enabled; other catalogue entries say In preparation. Non-English mobile support is not a new release requirement, but the original sample is never disabled. The English mobile target is retained in configuration; this PC implementation does not claim new mobile certification.

Audio: local browser voices preferred; online browser voices require explicit checkbox. Selecting a language is not proof a corresponding voice or recognition service is installed. If none exists, show a translated notice; never play an unrelated English voice silently. No new paid voice provider, API key or automatic cloud-voice retry. Additional questions use a separate bounded five-language API with the existing server key, store:false and response validation. This is not a promise of zero provider retention. Actual multilingual answer accuracy and deployment connectivity need live review. No per-switch AI translation calls. User questions are capped and no identifying student fields are requested. Prior GEM content restrictions are not replaced with national-curriculum defaults.

Data and media lists supplied in Information for students remain optional research candidates. No external videos or images are imported or treated as automatically licensed. Existing cloud/API/hosting usage still has its original costs; on-device rendering does not mean all operation is free.

Build: build-pc-five.mjs runs the unchanged full all-questions build, copies PC files, aligns language-pack explanation methods to their reused visual roles, then runs new regression tests. New tests check 450 language-number template cases plus a real shared VRM/geometry browser run across all ten problems and five languages. TTS/ASR is simulated; no physical PC or phone certification is implied. The separate workflow concurrency group does not cancel another window's checks.
