# AI practice workbook button — isolated programme extension

Base: 13fabaec87e8eff7566ac3fcbf1e09e0a74cd946, the latest saved common-programme work. The user's screenshot shows the earlier 6b3a505 programme deployment. This extension preserves the later microphone/transcript fixes and opt-in speech settings without enabling a paid voice service. It does not update production main, the source branch of the other conversation, or the old sample deployment.

A fifth card is appended beside the four existing unit cards. The card follows the visible grade and subject. Each confirmed click deliberately makes a fresh server request to the existing OpenAI configuration, rotating among the four unit themes for that grade/subject. It never substitutes a cached unit lesson for a new workbook. The current six-stage teaching format is preserved: explanation, question, group activity, question, question, recap. Thus each click creates three new questions with supporting teaching material, not a full annual syllabus or a ten-question worksheet. English/French/Nepali/Urdu/Swahili remain parallel translations of the same material. World history remains Grade 7+.

The new server adapter reuses runProgramme and its existing structural validation, content-policy rejection, independent answer review and bounded correction attempt. Only the generator instructions receive the workbook freshness requirement and bounded prior question data; reviewer instructions remain unchanged. A server UUID changes on each request. After review, repeated exact question content (prompt, board and order-independent choices) is rejected rather than displayed as new. Within-pack duplicate questions are also rejected. Up to 18 prior question keys for the selected unit are retained within the latest 48 successful workbook records on that browser. No cross-device/global uniqueness or detection of every semantic paraphrase is claimed.

Generation is never triggered by reload, language change, Continue, or catalogue rendering. Busy state prevents double-click duplication. Confirmation cancellation, generation failure and cancelled/stale responses preserve the previous lesson/progress, left paused. Only a validated successful result replaces the pack and resets progress. Workbook packs are not written into the normal unit cache. The teacher preview/approval step remains in place; the existing avatar, input, feedback, conversations and fullscreen controller run the generated lesson.

AI generation needs internet and uses the existing billable API. The new card displays this notice. No scheduled/background generation, new speech subscription, automatic paid voice activation, external media import or audio-path replacement is added. User-reported English/French working speech/text paths are preserved. Availability of Nepali/Urdu/Swahili device voices remains a separate issue; this patch does not certify those voices.

Build-workbook runs the entire inherited programme build, then a narrow final-output patch. Hash checks preserve the sample, avatar, audio tools, cloud-speech module, fullscreen controller and original programme/speech endpoints. Pure tests exercise freshness/rotation; server tests mock provider output but use the actual existing generator/reviewer pipeline; browser tests load the existing VRM and exercise clicks, failure/cancel, stale results, five languages, resume, microphone text receipt and fullscreen. When a server key exists, a separate live check requests two new workbooks in the same unit and verifies six distinct question records after independent review. Tests are not a guarantee of universal factual correctness or native-language quality, and physical microphones/speakers still need operator review.
